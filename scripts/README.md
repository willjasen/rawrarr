# Scripts

The coordinator Devices heading action has a focused source regression test under [`tests/`](tests/README.md): `node --test scripts/tests/test_rawrarr_devices_add_button.mjs`.

This project keeps a local Radarr inspection helper and repeatable checks under [`tests/`](tests/). See the [test index](tests/README.md) for coverage, dependencies, and invocation.

- `tests/test_orbstack_arr_connectivity.py` — Verify both fossil nodes and Tailscale sidecars have no host-published ports (`--ports-only` checks an existing environment), then check fossil unlocks its age vault, saves and reads back encrypted HTTPS connections, and loads Radarr/Sonarr status and library APIs through a private test CA. `--start` builds and starts the isolated `rawrarr-test-environment`; it requires Node.js and installed `rust-arr/web-export` modules. See the [test runbook](../runbooks/2026-10-26-fossil-port-forward-tests.md).

- `classify_internal_deploy_targets.py` — Compare two Git refs and emit JSON identifying whether internal coordinator, node, both, or neither targets need deployment. Coordinator SQLx migrations and coordinator-served signing source/assets are mapped explicitly; unknown Rawrarr runtime paths conservatively target both. Requires Python 3. Run `python3 scripts/classify_internal_deploy_targets.py --base origin/main --head HEAD`.

- `local_radarr.py` — read Radarr status and library totals using the node-local plaintext mirror in the local Docker container; never prints the API key or movie paths. Requires Python 3 and Docker access. Run `python3 scripts/local_radarr.py`.

- `setup_local_syncthing.py` — Bootstrap the existing MacBook `rawrarr-local-syncthing-1` for local review with global discovery and public relays enabled as connection fallback. Requires Python 3 and Docker OrbStack context. Dry-run by default; `--apply` backs up protected config and restarts only this container. Use after `docker compose -p rawrarr-local -f docker-compose.syncthing.yml up -d syncthing`; never add `--remove-orphans`. This bootstrap does not add remote peers or authorize production sharing: configure peers and folders only after owner approval. GUI: http://127.0.0.1:8385; set owner-selected credentials there before broader access.
- `share_storage_media.py` — Show a Syncthing device ID, inspect one media folder, or pair an explicitly selected `/media/...` folder or filtered `/media` root with an approved peer. Dry-run by default; `--apply` writes a send-only source or receive-only destination. The root option `--path /media --include-a-folders` requires the documented A/a `.stignore` base filter (with optional exact album additions) on both mounts and `.stfolder` on a read-only source. Requires Python 3 and a local Syncthing API key file or existing OrbStack Syncthing container; the root option requires a container preflight. A new destination needs `--confirm-empty-destination` after host-path inspection. Run once on each storage node with the same folder ID and verified opposite device ID.
- `publish_shared_output.py` — Copy one explicitly selected file tree into `/shared/out` so every peer already sharing the Syncthing `/shared` folder receives it. Dry-run by default; `--apply` copies missing files without overwriting or deleting. Requires Python 3, a readable source directory, the host path mounted as `/shared`, and enough free space. It does not configure Syncthing peers or mirror `/media` automatically.
- `migrate_shared_metadata.py` — Copy legacy `/shared/metadata` files into `/shared/in/metadata` while preserving the source and never overwriting destination files. Dry-run by default; before `--apply`, stop metadata writers and wait for Syncthing to become idle. Requires Python 3 and the host path mounted as `/shared`.
- `add_music_sync_albums.py` — Add exact `artist/album` allow patterns to an existing music `.stignore` without widening the entire artist. Dry-run by default; pass `--root HOST_MUSIC_DIR --album 'Artist/Album'` (repeat `--album`) and `--source` on the source host to require the albums to exist. Use `--apply` separately on source and destination after reviewing both previews. Requires Python 3; does not modify Syncthing devices or folders.
- `hash_media_tree.py` — Read-only JSON count, byte total, and path/content SHA-256 fingerprint for a folder. Run on source and replica after Syncthing reaches idle; matching outputs verify copied file bytes and relative paths. Requires Python 3.
- `lock_syncthing_to_tailscale.py` — Dry-run by default; `--apply` pins a two-device Syncthing pair to static Tailscale IPv4 TCP addresses and disables discovery, public relays, and NAT traversal. Requires Python 3 and existing local OrbStack Syncthing/Tailscale sidecars. Use with `docker-compose.syncthing-tailnet.yml` (`ALL_PROXY_NO_FALLBACK=1`) and verified Tailscale Serve TCP 22000 forwards on both hosts; read back the connection type afterward.
- `provision_node.py` — Prepare a trusted storage/metadata node credential and coordinator registry entry; Python 3, dry-run by default, `--apply` writes protected node state outside the checkout. See [container deployment](../docs/container-deployment.md).
