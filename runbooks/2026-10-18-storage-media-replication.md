> Historical deployment record. The operator confirmed the old Mac-specific
> storage setups obsolete on 2026-11-03. The MacBook storage template and Mini
> transport/relay templates are retired; current Macs host fossil subscribers.
> This does not remove media, Syncthing data, identities, or live containers.
> See [retirement and recovery](../docs/compose-layout.md#retired-host-specific-storage-and-relays).

## Objective and initial state

Add an explicit Syncthing setup path for sharing selected media folders from the Mac mini apex to a second MacBook apex node. The existing `rawrarr-shared` folder carries application data; storage nodes mount `/media` read-only in Rawrarr, and Syncthing did not initially mount media. The user selected only top-level music folders beginning with A or a, with the Mini as send-only source and the MacBook as receive-only destination. The Mini had two matching folders totaling about 3.3 GiB; the MacBook had about 139 GiB free.

Related context: [Syncthing peer sync](2026-10-17-rawrarr-syncthing-peer-sync.md), [Mac mini storage deployment](2026-10-18-mac-mini-storage-node-deployment.md).

## Recovery and remaining work

Keep source and destination media and both Syncthing state volumes. To pause replication, pause `rawrarr-media` in Syncthing on both peers; do not delete files or volumes. To undo the one-folder arrangement, remove its folder configuration on both peers, restore the previous `/media` mounts, and re-add the original artist folder IDs only if those scopes are still desired. To undo tailnet-only transport, first inspect current Serve handlers, then deliberately restore the prior Syncthing proxy/config values from protected node-local backups or the recorded pre-change values; do not reset Serve because the HTTPS routes are independent. If the tailnet route fails, `ALL_PROXY_NO_FALLBACK=1` intentionally stops sync rather than falling back to a public relay.

The MacBook apex remains pending until the owner approves it in roarlay Devices. Verify its healthy listener, media scan, and catalog appearance after approval. Media synchronization alone does not activate that node.
