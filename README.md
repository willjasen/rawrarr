# Rawrarr

Rawrarr is a self-hosted device-to-device file-sharing project with media automation as its first focused use case. It is an early Rust application, currently centered on Radarr integration, passkey sign-in, age-encrypted settings, local library scanning, and Syncthing-based app-data sharing. General-purpose file sharing, remote node claiming, and generated subscriber Compose files are product directions, not implemented features.

## Run locally

See the [user guide](docs/user-guide.md) for Docker Compose setup, passkey onboarding, age identity setup, and Radarr configuration. The Compose files in this repository are development/self-hosting examples; they are not yet generated by a hosted deployment portal.
