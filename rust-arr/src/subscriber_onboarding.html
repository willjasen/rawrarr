This user signing key authorizes node signing keys and their roles. The private key is encrypted to your age recipient in the backup. Save the backup and fingerprint somewhere safe; you can add a node whenever you are ready.

Node Compose setup ·

Set up a node on your own computer

Choose a fossil node for Radarr/Sonarr and encrypted library data, or a boneyard node when this computer has media files. Your account uses the existing roarlay; this installer offers no roarlay or coordinator role.

This name appears in the approval request and Devices list. You can change it later.

This independently pins the root key for the node. Keep the same fingerprint in future node Compose files.

Each node gets its own Tailscale identity and state. Enter a one-time auth key for the selected network. Internal Tailscale mode embeds the key in Compose; Headscale mode uses a local secret file.

Use the mini coordinator's Tailscale Serve URL. Nodes will use this address to register and contact their coordinator.

For internal Tailscale, the key is included in the downloaded Compose file. Keep that file private and remove the key after the node joins. Headscale mode stores it in a separate local secret file.

Docker Desktop must be allowed to access this folder. It mounts read-only.

Development preview: The public Rawrarr image has not been published. This Compose file uses rawrarr:local and will start only when that image is already present on the target computer. Public one-command installation remains pending.
