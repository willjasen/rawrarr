Add the connection details to the rawrarr service environment, then restart it. Your API key stays on the server and is never shown in this page.

1
Set RADARR_URL to your Radarr address, for example http://radarr:7878.
2
Set RADARR_API_KEY from Radarr’s General settings.
3
Restart rawrarr. This dashboard will show the connection result.
