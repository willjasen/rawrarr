Set up a rawrarr node

Sign-in uses your passkey. Your age private ID and encrypted signing-root backup stay in this browser while you work through these steps; they are never sent to roarlay. Save both backups somewhere you control.

1. Create or import your age ID

This ID unlocks encrypted rawrarr data. Keep a recoverable copy outside this browser.

2. Create or import your encrypted signing root

The owner signing root is separate from age. It will be needed for signed device approvals when that trust flow is released. Only its age-encrypted backup is copied. This preview does not yet pin the public root as an active trust anchor.

Keep both the encrypted root-key backup and the private age ID. Losing either can prevent future device approvals. Rawrarr cannot recover them for you.

3. Deploy on your own computer

Choose a fossil node for Radarr/Sonarr and encrypted library data, or a boneyard node when this computer has media files. Your account uses the existing roarlay; this installer offers no roarlay or coordinator role.

This name appears in the approval request and Devices list. You can change it later.

Each node gets its own Tailscale identity and state. Enter a one-time auth key for the selected network; Compose will reference a local secret file without including the key itself.

Use the mini coordinator's Tailscale Serve URL. Nodes will use this address to register and contact their coordinator.

The key stays in this browser until you download the files. Save it locally as tailscale-authkey beside compose.yaml, then remove it after the node joins.

Docker Desktop must be allowed to access this folder. It mounts read-only.

Development preview: The public Rawrarr image has not been published. This Compose file uses rawrarr:local and will start only when that image is already present on the target computer. Public one-command installation remains pending.
